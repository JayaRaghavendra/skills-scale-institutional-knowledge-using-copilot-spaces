# Role Interaction Matrix

Purpose: Quick reference to show primary collaborators and responsibilities across common activities.

| Role | Short summary | Works closely with |
|---|---|---|
| Project Manager (PM) | Delivery coordination, risk & communication | PdM, Delivery Lead, Stakeholders, Release Manager |
| Product Manager (PdM) | Defines what to build & success metrics | Devs, UX, Data, PM |
| Developers (Dev) | Build & maintain the product | PdM, QA, SRE, Security |
| QA / Testing | Validate acceptance criteria | Devs, PdM, Release Manager |
| Release Manager | Orchestrate releases & rollback | PM, Devs, QA, Support, SRE |
| Delivery Lead | Day-to-day delivery orchestration | PM, Devs, QA |
| SRE / Reliability | Production reliability & runbooks | Devs, Release Manager, PM |
| Data / Product Analyst | Metrics & experiment analysis | PdM, Devs |
| Design Researcher / UX | User research & UX acceptance | PdM, Devs, QA |
| Security / Compliance | Security reviews & compliance | Devs, PM, Release Manager |
| Customer Success / Support | Customer enablement & feedback | PM, Release Manager, Devs |

Notes:
- Use this matrix during planning and escalations to quickly identify who to involve.
- Keep interactions lightweight (one or two contacts) for rapid decisions, escalate to broader groups only for cross-cutting impacts.
